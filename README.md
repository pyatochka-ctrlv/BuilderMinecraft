# BuilderMinecraft

Генератор HTML/CSS-вставок для уроків курсу Minecraft Kids у білдері LMS GoITeens.

Відкрий `index.html` у браузері — збирання й залежності не потрібні.

1. Встав текст уроку з мітками (`#урок:`, `#назва:`, `#легенда:`, `#цілі:`, `#заголовок:`, `#розділювач`, `#порада:`, `#увага:`, `#перевір:`, `#місія:`, `#смуга`, `#дз:`, `#англійська:`, `#артефакт:`, `#наступний:`) і натисни «Розкласти по шаблону». Повна довідка — у самому інструменті.
2. Зміни кольори, емодзі та тексти в картках елементів.
3. Для кожної вставки натисни «Копіювати HTML» і «Копіювати CSS» та встав їх у білдер через кнопку `<>`.

Стан зберігається в `localStorage` браузера; для окремих уроків використовуй «Експорт JSON» / «Імпорт JSON».
